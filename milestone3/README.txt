IT 4403 - Individual Project Milestone 3
Open Library Single Page Application

Files:
- index.html: only main UI page
- css/styles.css: responsive stylesheet
- js/app.js: jQuery AJAX, search, pagination, details, collection

Features: Search by title/keywords; up to 50 results in views of 10; current-page indicator; selected Work details; up to 10 subjects; Fantasy subject collection; missing-cover fallbacks; empty-input, no-results, loading and request-error messages; cached Work details.

Endpoints:
https://openlibrary.org/search.json
https://openlibrary.org/works/{work_id}.json
https://openlibrary.org/subjects/fantasy.json?limit=10

Keep this in a separate Milestone 3 folder; do not overwrite Milestone 2. Deploy to Azure using the method approved by your course. The final PDF report must include the real Azure URL and GitHub repository URL on page one and readable screenshots showing search, pagination, selected details, collection, and validation/error handling.
